# Apartment Maintenance Management System

A cloud-based apartment maintenance management application built using
React and AWS serverless services.

## Problem

Apartment maintenance requests are often managed through informal channels
such as phone calls, messaging applications, or verbal communication.

This can make it difficult to track complaints, assign maintenance workers,
and monitor the resolution of issues.

## Objective

The objective of this project is to provide a centralized platform for
residents, administrators, and maintenance workers to manage maintenance
requests.

## User Roles

### Resident
- Submit maintenance requests
- Upload issue images
- Track request status
- View maintenance history
- Submit feedback

### Administrator
- View maintenance requests
- Assign workers
- Manage priorities
- Monitor request status
- View dashboard statistics

### Maintenance Worker
- View assigned requests
- Update work status
- Add resolution notes
- Mark requests as resolved

## Technology Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Cloud
- Amazon Cognito
- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
- Amazon S3
- Amazon CloudWatch

## Architecture

The project uses a serverless architecture to reduce infrastructure
management and cloud resource consumption.
